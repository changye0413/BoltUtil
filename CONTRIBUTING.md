# Contributing

BoltUtil is a proprietary hosted product. This repository accepts contributions only to its public documentation and merchant-side integration examples.

## Suitable contributions

- correct an inaccurate or unclear integration instruction;
- improve an existing example without adding secrets or production data;
- add a minimal merchant-side example in another language;
- report a broken public documentation link;
- suggest an integration-focused documentation improvement.

Before a large change, open a Discussion or Issue so the intended behavior can be confirmed.

## Pull request checklist

- Keep the change limited to public documentation or examples.
- Use placeholder credentials and example domains.
- Preserve HMAC verification, timestamp validation, and idempotency guidance.
- Ensure request paths, headers, network names, and payload fields match the current documentation.
- Run the relevant example syntax or compile check.
- Explain the user-facing reason for the change.

# Support

## Integration questions

Use [GitHub Discussions](https://github.com/changye0413/BoltUtil/discussions) for API integration questions, implementation patterns, and product feedback that can be discussed publicly.

Use an [Issue template](https://github.com/changye0413/BoltUtil/issues/new/choose) for a reproducible problem in the public documentation or examples.

For account-specific assistance, email **support@boltutil.com**.

## Information to include

- API endpoint and HTTP method;
- selected network;
- response status and sanitized error code;
- example language and runtime version;
- minimal steps to reproduce;
- expected and actual behavior.

Do not publish API keys, Webhook secrets, access tokens, complete wallet histories, private customer data, or private keys. Shorten transaction hashes and merchant order IDs unless the full value is required for private support.

Security concerns must follow [SECURITY.md](SECURITY.md), not a public Issue or Discussion.
